## 📌 STEP 0: 설교 전 체크리스트

**이 설교의 "짐"은 무엇인가?**
- [x] 내 마음을 무겁게 짓누르는 메시지가 있는가?

- [x] 어떤 대가를 치르고서라도 전하고 싶은가?

**짐(Burden)**:
```
청소년들이 바꿀 수 없는 것들(과거의 실수, 타인의 반응, 타고난 것들) 때문에
밤새 불안해하고 자책하며 에너지를 소모하고 있다.
그러는 동안 정작 바꿀 수 있는 것들(자신의 태도, 노력, 선택)은 놓치고 있다.

느헤미야는 2500년 전에 이미 "평온의 기도"를 살았던 사람이다.
바꿀 수 없는 것(무너진 성벽, 포로 역사, 왕의 마음)은 하나님께 맡기고,
바꿀 수 있는 것(자신의 태도, 용기 있는 요청, 철저한 준비)에 집중했다.

이 메시지를 통해 청소년들이 불필요한 불안에서 벗어나
자신이 할 수 있는 것에 집중하는 지혜를 얻기를 간절히 원한다.
```

- 바꿀 수 없는 것 하나를 하나님께 맡기는 기도를 드린다

```

- 바꿀 수 없는 것(무너진 성벽, 포로 역사, 왕의 마음)을 평온함으로 하나님께 맡기고

- 그 결과 52일 만에 성벽이 재건되었다

청소년들도 이 원리를 적용할 수 있다.
```

**Q2. 그와 관련해 청중들이 무엇을 하기 원하는가?**
```

3. 바꿀 수 있는 것 중 가장 작은 것 하나 실천하기
4. 평온의 기도를 매일 기도하기
```

## 🗺️ STEP 3: 지도 (MAP) - 어떻게 전달할 것인가?

### ME (나) - 설교자의 이야기 (2분)

**목적**: 청중과의 연결, 공감대 형성

**나의 경험/고민/질문**:
```
"여러분, 잠깐 손 들어볼까요? 요즘 스트레스 받고 있는 사람?
아, 거의 다네요.

저도 여러분 나이 때 그랬어요.
- 성적 때문에 스트레스 받고
- 친구 관계 때문에 밤새 고민하고
- 부모님이 이해 못 해주신다고 속상해하고

그런데 나중에 알았어요.
제가 그렇게 고민했던 것들 중에
절반 이상은 제가 어떻게 할 수 없는 것들이었다는 걸요.

이미 본 시험 점수, 친구의 마음, 과거의 실수...
아무리 생각해도 바꿀 수 없는 것들이었어요.

그런데 그걸 몰랐던 거죠.
그래서 바꿀 수 없는 것 때문에 에너지를 다 쓰고,
정작 바꿀 수 있는 것들은 놓쳤어요."
```

### WE (우리) - 공통의 문제 (3분)

**목적**: "나만 그런 게 아니구나" 확인

**우리가 공통적으로 겪는 문제**:
```
우리 모두 각자의 고민이 있어요:
- "성적이 안 나와요"
- "친구가 저를 오해하고 있어요"
- "부모님이 저를 이해 못 해주세요"
- "제 외모가 마음에 안 들어요"

그런데 이런 고민들을 가만히 들여다보면
재미있는 사실을 발견할 수 있어요.

어떤 것들은 내가 아무리 애를 써도 바꿀 수가 없다는 거예요.
```

**통계/연구/사례**:
```
바꿀 수 없는 것들:
- 이미 본 시험의 점수
- 친구의 마음
- 부모님의 성격
- 내 얼굴형, 키, 타고난 체형
- 과거에 일어난 일들

문제는 뭘까요?
우리는 종종 이렇게 바꿀 수 없는 것들 때문에
너무 많은 에너지를 소모한다는 거예요.

밤새 후회하고, 불안해하고,
"왜 나는 이럴까" "왜 저 사람은 저럴까" 생각하면서 말이죠.

그러는 동안 정작 우리가 바꿀 수 있는 것들은 놓치고 살아요.
```

### GOD (하나님) - 성경의 답 (8-10분)

**목적**: 하나님의 관점, 성경의 해결책 제시

**본문 읽기**: 느헤미야 1:1-11, 2:1-8

**본문의 배경 (간략히)**:
```
느헤미야는 페르시아 왕궁에서 왕의 술 맡은 관원으로 일하고 있었어요.
어느 날 끔찍한 소식이 전해집니다.
예루살렘, 하나님의 도성이 완전히 무너져 있다는 거예요.
성벽은 무너지고, 성문은 불에 타고, 백성들은 큰 곤난을 당하고 있었어요.
```

**본문이 말하는 핵심**:
```
1. 느헤미야가 바꿀 수 없었던 것들 (느 1:1-3)
   - 이미 무너진 성벽 (140년 전 파괴됨)
   - 이스라엘의 포로 역사 (조상들의 불순종 결과)
   - 자신의 신분 (왕의 종, 포로의 후손)
   - 왕의 마음 (허락 없이는 아무것도 할 수 없음)

2. 느헤미야의 반응: 평온함을 선택 (느 1:4-11)
   - 울고 슬퍼했지만 (감정 표현)
   - 하나님께 기도하며 맡김 (평온함)
   - "평온함 = 바꿀 수 없는 것을 하나님께 맡기는 것"

3. 느헤미야가 바꿀 수 있었던 것들 (느 2:1-8)
   - 자신의 마음과 태도 (정직하고 정중하게 표현)
   - 입을 여는 용기 (왕에게 요청하기)
   - 철저한 준비와 계획 (기한, 통행증, 목재까지 구체적 요청)

4. 핵심 구절 (느 2:8b)
   "내 하나님의 선하신 손이 나를 도우시므로 왕이 허락하시고"
   → 왕의 마음은 느헤미야가 바꿀 수 없었지만,
      느헤미야가 자신이 할 수 있는 것을 다 했을 때,
      하나님이 왕의 마음을 움직이셨다!
```

**The Point와의 연결**:
```
평온의 기도 (라인홀트 니버):
"하나님, 제게 평온함을 주시어 바꿀 수 없는 것들을 받아들이게 하시고,
용기를 주시어 바꿀 수 있는 것들을 변화시키게 하시며,
지혜를 주시어 그 둘을 분별할 수 있게 하소서."

느헤미야는 2500년 전에 이 기도를 삶으로 보여준 사람이다!

1. 평온함 (Serenity) → 바꿀 수 없는 것 받아들이기
2. 용기 (Courage) → 바꿀 수 있는 것 변화시키기
3. 지혜 (Wisdom) → 둘을 분별하기
```

### YOU (당신) - 개인적 적용 (5분)

**목적**: "그래서 내가 뭘 해야 하는데?" 답하기

**구체적 행동 1: 구분하기**
```
이번 주에:
지금 가장 여러분을 힘들게 하는 한 가지 문제를 생각하세요.
그리고 종이에 표를 만들어서 적어보세요.

|내가 바꿀 수 없는 것|내가 바꿀 수 있는 것|
|---|---|

예시:
"시험을 망쳤어요"
- 바꿀 수 없는 것: 이미 본 시험 점수
- 바꿀 수 있는 것: 다음 시험 준비, 공부 방법 바꾸기, 선생님께 질문하기

"친구가 나를 오해해요"
- 바꿀 수 없는 것: 친구의 생각, 이미 퍼진 소문
- 바꿀 수 있는 것: 친구에게 먼저 다가가기, 진심 담아 설명하기
```

**구체적 행동 2: 맡기기**
```
오늘부터:
바꿀 수 없는 것들을 보면서 기도하세요.

"하나님, 이것들은 제가 바꿀 수 없어요.
하나님께 맡겨요. 평온함을 주세요."

그리고 더 이상 그것 때문에 밤새 고민하지 마세요.
생각날 때마다 "아, 이건 하나님께 맡긴 거지" 하고 넘어가세요.
```

**구체적 행동 3: 실천하기**
```
지금 당장:
바꿀 수 있는 것들 중에서 딱 하나만 고르세요.
제일 쉬운 것으로요.

그리고 이번 주에 그걸 실천해보세요.

예시:
- "친구에게 먼저 '안녕' 하고 말 걸기"
- "하루 30분 복습하기"
- "부모님께 감사하다고 말씀드리기"
- "거울 보면서 밝게 웃기"

뭐든 좋아요. 작지만 구체적인 것 하나.
```

**적용 점검**:
- [x] 너무 추상적이지 않은가? → 구체적 표 작성, 구체적 행동 제시
- [x] 월요일 아침에 실천 가능한가? → 아주 작은 것 하나부터 시작
- [x] 측정 가능한가? → 표에 적기, 하나 실천하기
- [x] 누구나 할 수 있는가? → 각자의 상황에 맞는 예시 제공

## ✅ 막힐 때 돌아가는 5가지 질문

### Q1. 청중은 무엇을 알아야 하는가?
```
- 바꿀 수 없는 것과 바꿀 수 있는 것이 있다
- 느헤미야는 이 둘을 구분하고 지혜롭게 대응했다
- 바꿀 수 없는 것은 하나님께 맡기는 것이 평온함이다
- 바꿀 수 있는 것에 집중하는 것이 용기다
- 둘을 분별하는 것이 지혜다
```

### Q2. 왜 그것을 알아야 하는가?
```
- 청소년들이 바꿀 수 없는 것 때문에 너무 많은 에너지를 낭비하고 있다
- 불필요한 불안, 자책, 후회로 시간을 허비하고 있다
- 정작 바꿀 수 있는 것들을 놓치고 있다
- 이 원리를 알면 평온함과 집중력을 얻을 수 있다
- 하나님이 일하시는 것을 경험할 수 있다
```

### Q3. 청중은 무엇을 해야 하는가?
```
1. 자신의 문제를 표로 만들어 구분하기
2. 바꿀 수 없는 것은 하나님께 맡기는 기도 드리기
3. 바꿀 수 있는 것 중 가장 작은 것 하나 실천하기
4. 평온의 기도를 매일 기도하기
```

### Q4. 왜 그것을 해야 하는가?
```
- 불안에서 벗어나기 위해
- 에너지를 올바른 곳에 집중하기 위해
- 실제 변화를 경험하기 위해
- 느헤미야처럼 하나님이 쓰시는 사람이 되기 위해
- 52일 만에 성벽이 재건된 것 같은 놀라운 변화를 보기 위해
```

### Q5. 청중이 보다 잘 기억하게 하려면 어떻게 해야 하는가?
```
- 평온의 기도를 3번 이상 반복
- The Point를 5번 이상 반복
- 표를 시각화 (PPT)
- 구체적인 예시 제공 (시험, 친구, 부모님, 외모)
- 카드 나눠주기 (평온의 기도 인쇄)
- 52일 성벽 재건이라는 숫자 강조
```
