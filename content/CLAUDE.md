# CLAUDE.md — AI-PK M-System Vault Schema

이 파일은 Claude가 이 Obsidian vault를 어떻게 읽고, 쓰고, 유지해야 하는지를 정의합니다.
vault의 "헌법"입니다. 모든 세션 시작 시 반드시 읽으세요.

---

## 1. Vault 개요

이 vault는 **신학 연구, 개인 지식 관리, 독서, 창작**을 위한 개인 지식 베이스입니다.
LLM Wiki 패턴을 따릅니다: Claude가 wiki를 유지하고, 사용자는 소스를 공급하고 질문합니다.

**범위**: 신학·성경 연구 중심이되, 인문·사회·문화 등 개인이 축적하고 싶은 지식 전반을 포괄합니다.
**사역 관련 기록(회의록, 프로그램 계획 등)은 별도 볼트에서 관리합니다.**

**언어**: 기본적으로 한국어로 작성합니다. 학술 용어나 고유명사는 영문 병기 가능.

## 3. Frontmatter 컨벤션

모든 wiki 파일(영구노트, 개념노트, MOC)의 frontmatter:

```yaml
---
date: YYYY-MM-DD          # 생성일
updated: YYYY-MM-DD       # 마지막 수정일
type: permanent | concept | moc | output
tags:
  - 태그1
  - 태그2
sources:                  # 참조한 소스 파일 (선택)
  - "[[파일명]]"
---
```

---

## 4. 파일명 컨벤션

- **영구노트**: `주제-세부주제.md` (한국어, 하이픈 구분) — 예: `느헤미야-기도신학.md`
- **개념노트**: `개념명.md` — 예: `케노시스.md`
- **MOC**: `주제명_MOC.md` 또는 `🗺️ 주제명-MOC.md`
- **문헌메모**: `YYYY-MM-DD_저자_제목_요약.md` 또는 기존 컨벤션 유지
- **출력물**: `YYYY-MM-DD_종류_제목.md`

## 5. Ingest 워크플로우

새 소스(클리핑, 책 챕터, 논문, 설교 등)를 처리할 때:

1. **읽기**: 소스 파일을 읽고 핵심 내용 파악
2. **대화**: 사용자와 주요 통찰, 강조할 부분 확인 (선택)
3. **문헌메모 작성**: `📁 2.Literature_Notes(문헌메모)/`에 요약 파일 생성
4. **영구노트 업데이트**: 관련 영구노트(`📁 3.Permanent_Notes(영구메모)/`)에 새 통찰 통합. 기존 내용과 모순되면 명시적으로 표시
5. **개념노트 업데이트**: 새로 등장한 개념이나 강화된 개념은 `📁 5. 개념노트/` 업데이트
6. **MOC 업데이트**: 관련 MOC에 링크와 한 줄 설명 추가
7. **wiki-index.md 업데이트**: 새로 생성/수정된 파일 반영
8. **wiki-log.md 기록**: 아래 형식으로 append

```
## [YYYY-MM-DD] ingest | 소스 제목
- 생성/수정한 파일 목록
- 주요 통찰 한두 줄
```

보통 소스 하나를 ingest하면 5~15개 파일에 영향을 줍니다.

## 6. Query 워크플로우

사용자가 질문하면:

1. `wiki-index.md` 먼저 읽기 → 관련 페이지 파악
2. 관련 MOC, 영구노트, 개념노트 읽기
3. 답변 합성 (wiki 페이지 링크로 출처 표시)
4. **중요**: 좋은 답변은 새 파일로 wiki에 저장
   - 비교 분석 → `📁 3.Permanent_Notes(영구메모)/` 또는 `📁 4.Prolific_Lounge (창작작업장)/`
   - 개념 정리 → `📁 5. 개념노트/`
5. `wiki-log.md`에 기록:

```
## [YYYY-MM-DD] query | 질문 요약
- 참조한 파일들
- 생성한 파일 (있다면)
```

## 7. Lint 워크플로우

사용자가 "wiki 점검해줘" 또는 `/lint` 요청 시:

다음을 검사하고 보고서 작성:
- [ ] 인바운드 링크 없는 고아 페이지
- [ ] 서로 모순되는 클레임
- [ ] 최신 소스로 업데이트가 필요한 오래된 내용
- [ ] 언급은 됐지만 개념노트가 없는 중요 개념
- [ ] MOC에 연결되지 않은 영구노트
- [ ] 추가 조사가 필요한 지식 공백

---

## 8. 글쓰기 원칙

- 영구노트는 **아이디어 중심**으로 — 출처가 아닌 통찰을 중심으로
- 개념노트는 **정의 + 신학적/학문적 함의 + 실천적 적용** 3단 구조
- MOC는 **허브** — 내용보다 연결이 목적
- 모순이나 긴장은 숨기지 말고 명시 (예: `> ⚠️ 이 주장은 [[다른파일]]의 내용과 긴장 관계`)
- 출력물(`📁 4.Prolific_Lounge (창작작업장)/`)은 wiki를 **컴파일**하는 것 — wiki에서 끌어다 씀

## 9. 현재 주요 연구/관심 주제

- **성경 인물 연구**: 느헤미야, 다니엘, 고레스
- **신학**: 종교개혁, 상황신학, 케노시스 기독론, 기도신학
- **설교 및 창작**: 설교 초안·시리즈, 에세이
- **문화·사회 분석**: 고맥락/저맥락 의사소통, 테크노-봉건주의, Gen Z
