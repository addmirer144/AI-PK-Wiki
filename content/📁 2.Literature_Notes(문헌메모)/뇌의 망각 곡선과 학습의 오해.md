# 뇌의 망각 곡선과 학습의 오해

## 뇌의 기본 설계
- **자동 정리 시스템**: 사용하지 않는 정보를 자동으로 정리
- **망각 속도**: 학습 후 하루만 지나도 내용의 **70%가 사라짐**
- **효율성 우선**: 뇌는 생존에 필요 없다고 판단하는 정보를 빠르게 삭제

## 일반적인 학습 오해
### 정보 소비 중심의 접근
- 유튜브 2배속 시청
- 책을 빠르게 읽기
- 더 많은 강의 수강

### 진짜 중요한 것
- **정보의 양 < 뇌에 남은 정보의 질**
- 소화되지 못한 정보는 결국 사라짐
- **소비와 소화의 균형**이 핵심

## 해결책
정보 **소비**와 **소화**를 분리하여 체계적으로 접근
