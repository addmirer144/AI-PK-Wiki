# 기업 AI 도입의 과도기적 현황

- **생성일**: 2025-01-16

## 핵심 개념

현재 기업들은 AI 도입에 있어 보안 이슈로 인해 과도기를 겪고 있다. 기업의 AI 사용 제한 정책으로 인해 직원이 사비와 개인 시간을 들여 AI를 사용해 업무를 처리하는 'AI 역체감 딜레마'가 발생하고 있다.

### 기업별 AI 도입 전략의 다양성

#### 폐쇄형 모델
- **대상**: 보안 시설로 지정된 기업
- **방식**: 메타의 라마(Llama) 같은 LLM을 로컬 서버에 다운로드하여 외부망과 단절된 환경에서 운영
- **특징**: 완전한 데이터 격리 보장

#### 선택적 개방형 모델  
- **대상**: 정보 보안에 덜 민감한 영역 (HR 리더십 코칭 등)
- **방식**: 외부 거대 언어 모델의 API 연결 활용
- **특징**: 기능성과 보안의 균형점 추구

#### 클라우드 기반 통합형 (미래 트렌드)
- **특징**: MS 코파일럿, 구글 워크스페이스 AI처럼 클라우드 기반 업무 시스템에 기본 기능으로 내장
- **전망**: 기업 데이터의 클라우드(Azure, AWS) 집중화에 따른 필연적 트렌드

### Suno.so를 활용한 내부 구현 전략
- **개념**: 오픈소스 프로젝트를 활용한 기업 내부 에이전트 구축
- **장점**: 외부 API 대신 내부 레가시 시스템의 API와 연동 가능
- **결과**: 맞춤형 에이전트 AI로 내부 시스템 데이터 분석 및 통합 답변 제공
