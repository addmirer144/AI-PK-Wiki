# 컬러베스 효과와 문제 중심 학습

## 컬러베스 효과 (Collaber's Effect)
**우리가 중요하다고 생각하는 것에 뇌가 더 주의를 기울이는 현상**

## 학습 전 준비 과정
1. **해결하려는 문제를 명확히 하기**
  - 종이에 문제 적기
  - PARA 시스템 활용
  - 구체적인 목표 설정

2. **뇌의 필터링 활성화**
  - 문제가 명확하면 관련 정보에 더 집중
  - 책이나 강의에서 해결책을 더 쉽게 발견
  - 불필요한 정보는 자동으로 걸러냄

## 실천 방법
- 학습 시작 전 5분간 문제 정의
- "이 책/강의를 통해 무엇을 해결하고 싶은가?" 질문
- 학습 목적을 구체적으로 문서화

## 연결점
설교 준비에서도 동일: 회중의 구체적 필요를 먼저 파악하면 본문에서 관련 내용을 더 잘 발견
