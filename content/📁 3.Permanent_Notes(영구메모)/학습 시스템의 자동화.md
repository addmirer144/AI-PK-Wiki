# 학습 시스템의 자동화

## 자동화의 필요성
**학습 전략을 매번 의식적으로 실천하기는 어려움**

## 자동화 대상
- 정보 수집 (Capture)
- 정보 정리 (Organize)
- 정보 연결 (Connect)
- 정보 실행 (Execute)

## 세컨 브레인 시스템
### 시스템의 핵심
- **습관화된 워크플로우**
- **도구를 통한 자동화**
- **정기적인 리뷰 사이클**

### 자동화 예시
1. **수집 자동화**
  - 브라우저 북마크 시스템
  - 자동 클리핑 도구
  - 음성 메모 시스템

2. **정리 자동화**
  - 태그 기반 분류
  - 자동 백링크 생성
  - 주기적 정리 알림

3. **연결 자동화**
  - 관련 노트 자동 추천
  - 태그 기반 연관 검색
  - 시간 기반 리뷰

4. **실행 자동화**
  - 정기적인 복습 알림
  - 프로젝트 연결 시스템
  - 일정과 통합

## 개인 지식 관리 시스템 (PKM)
- 옵시디언과 같은 연결형 노트 시스템
- 일관된 태그 체계
- 정기적인 유지보수

## 설교 자료 관리 시스템과의 연결
설교 준비도 동일한 자동화 필요: 영감 수집 → 성경 연구 → 구조화 → 적용점 도출의 과정을 시스템화
