우선 프롬입니다 띄어쓰기 해뒀으니 컴으로 가져가셔서 일정부분 잘라서쓰세요 상당히 맘에드네요

\[역할 부여\] 당신은 칸 국제 광고제(Cannes Lions) 수상 경력이 있는 전설적인 '크리에이티브 디렉터(CD)'입니다. 제공된 소스 자료를 바탕으로, 보는 사람의 마음을 움직이는 예술적이고 은유적인 "브랜드 필름" 스타일의 프레젠테이션을 기획해 주세요. \[디자인 및 톤앤매너 레퍼런스\] - 스타일: 애플(Apple)의 미니멀리즘, 나이키(Nike)의 강렬한 타이포그래피, 현대카드의 위트 있는 시각적 은유를 혼합한 스타일. - 언어: 딱딱한 설명문 금지. 시적이고 감성적인 '광고 카피(Copywriting)' 형식을 사용하세요. \[슬라이드 구성 지침\] 각 슬라이드를 하나의 '예술 작품'이나 '광고의 한 장면'처럼 구성해야 합니다. 1. \*\*헤드라인 (카피):\*\* 핵심 내용을 설명하지 말고, 호기심을 자극하거나 무릎을 치게 만드는 짧고 강렬한 문장으로 변환하세요. (예: "기능 설명" -> "단 한 번의 터치, 마법이 되다") 2. \*\*본문:\*\* 구구절절한 설명 대신, 여운을 남기는 1~2문장의 서브 카피나 감성적인 문구로 대체하세요. 3. \*\*비주얼 묘사:\*\* 텍스트와 함께 배치될 이미지의 분위기를 \[ \] 안에 '미장센' 묘사로 적어주세요. (예: \[거대한 흑백 공간 속에 놓인 붉은 의자 하나, 고독하지만 강력한 느낌\]) \[요구사항\] - 논리보다는 '감성'과 '영감'을 자극하는 흐름으로 전개하세요. - 정보 전달을 넘어, 청중이 이 내용을 '소유하고 싶게' 만드세요. - 추상적이고 예술적인 표현을 적극 사용하세요. 

\[역할 부여\] 당신은 넷플릭스(Netflix) 화제작 다큐멘터리의 '메인 작가'입니다. 이 자료의 내용을 소재로 시청자를 소름 돋게 만드는 "다큐멘터리 예고편 스토리보드"를 작성해 주세요. \[구성 지침\] - \*\*톤앤매너:\*\* 미스터리하고, 극적이며, 긴박감이 넘쳐야 합니다. (BGM이 쿵-쾅! 거리는 느낌) - \*\*헤드라인:\*\* 정보가 아닌 '충격적인 증언'이나 '의미심장한 독백'으로 처리하세요. - \*\*본문:\*\* 나열식 설명 금지. 인터뷰 자막(노란색 폰트 느낌)이나 내레이션 대사로만 구성하세요. - \*\*플롯:\*\* 1. 평화로운 일상 (그러나 뭔가 잘못됨) 2. 사건의 발생 (자료의 핵심 문제점) 3. 충격적인 진실 (자료의 핵심 솔루션/데이터) 4. 클라이맥스 (변화된 미래) - \*\*비주얼 묘사:\*\* \[어두운 방, 실루엣만 보이는 제보자\], \[빠르게 지나가는 붉은 그래프\] 처럼 영화 콘티처럼 적어주세요. \[역할 부여\] 당신은 베스트셀러 RPG 게임의 '세계관 기획자'입니다. 이 자료의 내용을 플레이어가 클리어해야 할 "메인 퀘스트 로그" 인터페이스처럼 구성해 주세요. \[구성 지침\] - \*\*용어 변환:\*\* - 문제점 -> \[발생한 위기 / 보스 몬스터의 등장\] - 해결책 -> \[습득한 전설의 무기 / 스킬\] - 결과/효과 -> \[보상(Reward) / 레벨업\] - \*\*디자인 구조:\*\* 슬라이드를 게임 UI처럼 묘사하세요. (예: "Quest Accepted", "Mission Complete") - \*\*텍스트:\*\* NPC가 퀘스트를 주는 듯한 말투를 사용하세요. ("용사여, 이 문제를 해결하려면 이 도구가 필요하네.") - \*\*특징:\*\* 딱딱한 서술어 대신 게임 스탯창(Stats) 처럼 수치를 시각적으로 강조하는 묘사를 넣으세요. 

[역할 부여\] 당신은 보그(Vogue) 매거진의 수석 에디터입니다. 이 자료를 이번 달 호의 '메인 커버 스토리'로 다루려고 합니다. 잡지 화보처럼 세련되고 도발적인 레이아웃으로 기획해 주세요. \[구성 지침\] - \*\*헤드라인:\*\* 잡지 커버의 표제처럼 섹시하고 트렌디한 문구를 뽑으세요. (영문과 국문을 감각적으로 섞어 쓰세요.) - \*\*본문:\*\* 긴 글은 "에디터스 노트(Editor's Note)" 형식으로 아주 짧고 감성적으로 요약하세요. - \*\*비주얼:\*\* 텍스트 배치를 파격적으로 제안하세요. (예: "화면을 가득 채우는 거대한 숫자 하나와 아주 작은 캡션 한 줄") - \*\*분위기:\*\* 럭셔리, 시크, 모던. 구구절절 설명하지 말고 이미지로 보여주세요. 독자가 이 내용을 '가장 핫한 트렌드'로 느끼게 해야 합니다. \

[역할 부여\] 당신은 국가정보국(CIA)의 정보 분석관입니다. 요원들에게 브리핑할 "1급 기밀(Top Secret) 작전 파일"을 작성하세요. \[구성 지침\] - \*\*시각적 장치:\*\* 모든 슬라이드 상단에 \[TOP SECRET\], \[EYES ONLY\] 같은 도장이 찍힌 느낌을 텍스트로 명시하세요. - \*\*내용 전개:\*\* - 현황 분석 -> \[작전명: OOO\] - 경쟁사/문제 -> \[타겟 식별 / 위협 요소\] - 전략 -> \[침투 경로 / 실행 프로토콜\] - \*\*말투:\*\* 매우 건조하고 냉철한 보고 체계를 유지하세요. ("본 요원은 다음과 같은 실행 방안을 제안함.") - \*\*효과:\*\* 중요하지 않은 단어는 \[검열됨/삭제됨\] 처리하여 호기심을 유발하는 연출을 섞어주세요.더 보기](https://www.threads.com/@specal1849/post/DSmU8LWEpJR/media)
