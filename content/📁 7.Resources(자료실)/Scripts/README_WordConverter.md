# Word to Markdown 자동 변환기

> 🚀 **서브어시스턴트**: 볼트 내 Word 파일을 Obsidian에 적합한 마크다운으로 자동 변환

## 🎯 개요

이 도구는 Obsidian 볼트에 저장된 Word 파일(.docx, .doc)을 마크다운 형식으로 자동 변환하는 서브어시스턴트입니다. 설교문, 연구 노트, 회의록 등 Word로 작성된 문서들을 Obsidian의 지식 관리 시스템에 통합할 수 있습니다.

## ✨ 주요 기능

### 🔄 자동 변환 시스템
- **일괄 변환**: 볼트 내 모든 Word 파일을 한 번에 변환
- **선택적 변환**: 특정 파일만 골라서 변환
- **실시간 감시**: 새로운 Word 파일이 추가되면 자동으로 변환

### 📝 Obsidian 최적화
- **메타데이터 자동 생성**: Frontmatter에 생성일, 수정일, 변환일 등 추가
- **태그 자동 분류**: 파일명 분석으로 #새벽묵상, #청소년설교 등 자동 태그
- **연결 가능한 형태**: [[링크]] 형식으로 다른 노트와 연결 가능

### 🖼️ 미디어 처리
- **이미지 추출**: Word 파일 내 이미지들을 별도 폴더로 추출
- **첨부파일 관리**: 모든 미디어 파일을 체계적으로 정리

### 🛠️ 이중 엔진 시스템
- **Pandoc**: 설치 시 고품질 변환 (권장)
- **Python**: Pandoc 미설치 시 순수 Python 기반 변환

## 🚀 빠른 시작

### 1단계: 설치
```bash
# 터미널에서 볼트 디렉토리로 이동
cd "볼트경로"

# 초기 설정 (의존성 자동 설치)
./convert.sh --setup
```

### 2단계: 사용
```bash
# 모든 Word 파일 변환
./convert.sh

# 특정 파일 변환
./convert.sh --file "설교문.docx"

# 자동 감시 모드
./convert.sh --watch
```

## 📁 파일 구조

```
볼트/
├── convert.sh                    # 간편 실행 스크립트
├── word_to_markdown.py          # Pandoc 기반 변환기 (고품질)
├── word_to_markdown_python.py   # Python 기반 변환기 (호환성)
├── watch_and_convert.py         # 실시간 감시 서비스
└── 📁 2.Processed_Notes(가공된노트)/
    ├── 변환된_파일.md
    ├── attachments/
    │   ├── image1.png
    │   └── image2.jpg
    └── word_conversion_log.md
```

## 🏷️ 자동 태그 시스템

파일명을 분석하여 자동으로 적절한 태그를 부여합니다:

| 파일명 키워드 | 자동 태그 |
|-------------|----------|
| `새벽` | `#새벽묵상` |
| `청소년` | `#청소년설교` |
| `아침묵상` | `#아침묵상` |
| `마태복음`, `마가복음` 등 | `#복음서` |
| `신명기`, `룻기` 등 | `#구약` |
| 모든 파일 | `#설교`, `#변환됨` |

## 📋 변환 결과물 예시

```yaml
---
id: 20250924141207
type: processed
created: 2025-03-30 21:03
updated: 2025-09-24 10:46
converted: 2025-09-24 14:12
original_file: 설교문.docx
tags: #새벽묵상 #복음서 #설교 #변환됨
---

# 설교 제목

> **원본**: `설교문.docx`  
> **변환일시**: 2025-09-24 14:12:07

[변환된 내용...]
```

## 🔧 고급 사용법

### 커스텀 출력 경로
```bash
python3 word_to_markdown_python.py --output /custom/path
```

### Dry-run 모드 (변환 없이 파일 목록만 확인)
```bash
python3 word_to_markdown_python.py --dry-run
```

### 백그라운드 감시 (추후 구현 예정)
```bash
./convert.sh --watch --daemon
```

## 🚨 문제 해결

### 일반적인 오류들

**"Pandoc이 설치되어 있지 않습니다"**
```bash
# 해결: Python 버전 사용
python3 word_to_markdown_python.py --install-deps
```

**"Permission denied"**
```bash
chmod +x convert.sh
chmod +x *.py
```

**변환 실패**
- Word 파일이 손상되었는지 확인
- 다른 프로그램에서 파일을 열고 있지 않은지 확인
- 파일 경로에 특수문자가 있는지 확인
