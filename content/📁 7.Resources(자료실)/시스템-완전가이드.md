# 📚 목회자용 제텔카스텐 시스템 - 완전 가이드

**시스템 구축일**: 2025-12-18  
**시스템 철학**: "완성본 먼저, 정리는 나중" (역방향 제텔카스텐)

---

## 🎯 시스템 개요

### 기존 문제점

1. **Permanent Notes 부족** (23개만 존재)
   - Literature Notes 178개인데 전환율 13%
   - 이상적 전환율: 30-50%

2. **처리 파이프라인 막힘**
   - Fleeting → Literature → Permanent 흐름 정체
   - 재료는 많은데 건축 안 됨

3. **목회자의 현실**
   - 설교 마감에 쫓김
   - 정리할 시간 없음
   - 완성본만 계속 생산

### 해결책: 역방향 제텔카스텐

```
전통적: Input → 정리 → 통찰 → Output
목회자용: Input → Output → 추출 → 제텔카스텐
                   ↓
              설교 완성 (우선!)
                   ↓
          주말 15-90분 투자
                   ↓
         Permanent Note 추출
```

## 🔄 3단계 루틴

### Level 1: 최소 루틴 (주당 15분) ⭐ **여기서 시작!**

**언제**: 설교 완성 직후 또는 월요일

**무엇**: 
1. 설교에서 핵심 통찰 1개 찾기 (3분)
2. Permanent Note 빠른 작성 (10분)
3. 저장! (2분)

**워크플로우**: `/extract-permanent-note-quick`

**결과**: 연간 50개 Permanent Notes

---

### Level 2: 표준 루틴 (주당 90분)

**언제**: 토요일 오후

**무엇**:
1. 설교 다시 읽기 (15분)
2. Permanent Note 1-2개 작성 (40분)
3. 연결 만들기 (20분)
4. Literature Notes 정리 (15분)

**워크플로우**: `/weekly-zettelkasten-mining`

**결과**: 연간 100개 Permanent Notes + 연결망

---

### Level 3: 완전 루틴 (월말 2-3시간)

**언제**: 월말 토요일

**무엇**:
1. 통계 확인 (15분)
2. Fleeting Notes 비우기 (30분)
3. Literature Notes 선별 (40분)
4. Permanent Notes 품질 향상 (40분)
5. 시스템 최적화 (20분)
6. 다음 달 계획 (15분)

**워크플로우**: `/monthly-cleanup`

**결과**: 깔끔한 시스템 + 지식 연결망 강화
