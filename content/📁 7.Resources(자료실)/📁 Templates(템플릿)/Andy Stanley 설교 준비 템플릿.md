
## 🗺️ STEP 3: 지도 (MAP) - 어떻게 전달할 것인가?

### 핵심 원칙
> "ME(나) → WE(우리) → GOD(하나님) → YOU(당신) → WE(우리)"
> "가장 짧고 명확한 길을 제시하라"

### ME (나) - 설교자의 이야기 (2-3분)

**목적**: 청중과의 연결, 공감대 형성

**나의 경험/고민/질문**:
```
(개인적 이야기, 실패담, 궁금증)
- 이야기 시작점:
- 감정 표현:
- 공감 포인트:




```

---

### WE (우리) - 공통의 문제 (3-4분)

**목적**: "나만 그런 게 아니구나" 확인

**우리가 공통적으로 겪는 문제**:
```
(청중이 고개를 끄덕일 수 있는 보편적 경험)
- 문제 1:
- 문제 2:
- 문제 3:




```

**통계/연구/사례**:
```
(이 문제의 심각성을 보여주는 데이터나 이야기)




```

---

### GOD (하나님) - 성경의 답 (5-6분)

**목적**: 하나님의 관점, 성경의 해결책 제시

**본문 읽기**: ________________________

**본문의 배경 (간략히)**:
```
(역사적, 문화적 맥락 - 최소한만)




```

**본문이 말하는 핵심**:
```
1.


2.


3.


```

**The Point와의 연결**:
```
(본문이 어떻게 The Point를 뒷받침하는가?)




```

---

### YOU (당신) - 개인적 적용 (3-4분)

**목적**: "그래서 내가 뭘 해야 하는데?" 답하기

**구체적 행동 1**:
```

```

**구체적 행동 2**:
```
오늘부터:




```

**구체적 행동 3**:
```

```

**적용 점검**:
- [ ] 너무 추상적이지 않은가?
- [ ] 월요일 아침에 실천 가능한가?
- [ ] 측정 가능한가?
- [ ] 누구나 할 수 있는가?

---

### WE (우리) - 공동체적 비전 (2-3분)

**목적**: "우리가 함께 이렇게 되자" 제시

**우리가 함께 이루어갈 변화**:
```
(공동체적 비전, 교회의 미래 모습)




```

**마무리 비전 선언**:
```
(청중이 함께 외치거나 다짐할 수 있는 문장)

"우리 _________________ 합시다!"




```

## 📊 설교 최종 점검 체크리스트

### 내용 점검
- [ ] **The Point가 명확한가?** (한 문장으로 요약 가능)
- [ ] **정보보다 적용이 많은가?** (정보 30% / 적용 70%)
- [ ] **21세기 청중의 문제를 다루는가?**
- [ ] **ME-WE-GOD-YOU-WE 구조가 있는가?**
- [ ] **불필요한 부분을 제거했는가?**

### 전달 점검
- [ ] **도입부가 흥미로운가?** (처음 30초가 결정적)
- [ ] **전환이 자연스러운가?**
- [ ] **기억에 남는 문구가 있는가?**
- [ ] **시각적 요소가 준비되었는가?**
- [ ] **마무리가 강력한가?**

### 변화 점검
- [ ] **청중이 무엇을 할지 명확한가?**
- [ ] **월요일 아침에 실천 가능한가?**
- [ ] **짐(burden)을 느끼는가?**
- [ ] **이 설교로 사람들이 변화할 것이라 믿는가?**

### 시간 점검
- [ ] ME: _____분 (2-3분 권장)

- [ ] GOD: _____분 (5-6분 권장)
- [ ] YOU: _____분 (3-4분 권장)
- [ ] WE: _____분 (2-3분 권장)
