# 주간 15분 제텔카스텐 루틴 가이드

**목표**: 바쁜 목회자를 위한 최소 시간 투자로 최대 효과를 내는 제텔카스텐 유지 루틴

**핵심 철학**: "역방향 제텔카스텐" - 설교(Output)가 먼저, 정리는 나중

---

## 🎯 왜 주 15분인가?

- **지속 가능성**: 부담 없이 평생 유지할 수 있는 최소 시간
- **습관 형성**: 작은 루틴이 큰 변화를 만듦
- **복리 효과**: 매주 15분 × 52주 = 연간 13시간의 누적 정리
- **목회 맞춤형**: 설교 준비에 집중하면서도 지식 자산 축적

---

## ⏰ 루틴 타이밍

### 권장 시간
- **매주 월요일 오전** (설교 후 휴식 → 다음 주 준비 전환점)
- 또는 **토요일 오전** (주간 마무리 + 안식일 준비)

### 필수 조건
- 방해받지 않는 조용한 시간
- 타이머 설정 (정확히 15분)
- Obsidian 볼트 열기

---

## 📋 15분 루틴 체크리스트

### 🗑️ 1단계: 정리 (5분)

**Inbox 확인 및 분류**
```
☐ 📁 0. Inbox 열기
☐ 파일 개수 확인 (목표: 5개 이하 유지)
☐ 각 파일을 빠르게 스캔하고 이동:
  - 설교/묵상 → 📁 4.Prolific_Lounge
  - 사역 관련 → 📁 6. 사역 및 회의노트
  - 책/자료 발췌 → 📁 2.Literature_Notes
  - 아이디어 메모 → 📁 1.Fleeting_Notes
```

**Tips**:
- 5초 이상 고민되면 일단 Fleeting_Notes로
- 완벽한 분류보다 빠른 결정이 중요
- Inbox = 0 달성 시 즉시 다음 단계로

---

### 🔄 2단계: 승격 (5분)

**임시메모 → 영구메모 변환**

```
☐ 📁 1.Fleeting_Notes 열기
☐ 가장 오래된 파일 3개 선택
☐ 각 파일 평가:

  ✅ 승격 조건 (하나라도 해당되면 승격):
  - 설교에 3번 이상 인용한 개념인가?
  - 다른 노트와 2개 이상 연결 가능한가?
  - 한 문장으로 핵심 통찰을 설명할 수 있는가?

  ➡️ 승격 액션:
  - 제목을 명확한 주장/개념으로 수정
  - YAML frontmatter 타입 변경: fleeting → permanent
  - 2-3개 관련 노트에 [[링크]] 추가
  - 📁 3.Permanent_Notes로 이동

  ⏸️ 유지 조건:
  - 아직 충분히 발전하지 않음
  - 추가 자료 수집 필요
  → 그대로 두기
```

**목표**: 주 1-2개 영구메모 생성 = 연간 52-104개 축적

---

### 🔗 3단계: 연결 (5분)

**우연한 발견 시간 (Serendipitous Connections)**

```
☐ 방금 승격한 영구메모 1개 열기
☐ Smart Connections 플러그인으로 유사 노트 찾기
☐ 또는 랜덤하게 📁 3.Permanent_Notes 1개 열기
☐ 두 노트 사이의 연결 고리 찾기:

  질문 리스트:
  - 이 두 개념이 서로를 어떻게 설명하는가?
  - 반대되는 지점은 무엇인가?
  - 설교에서 함께 사용할 수 있는가?
  - 새로운 통찰이 떠오르는가?

☐ 연결 표시:
  - 각 노트에 상대방 [[링크]] 추가
  - 간단한 연결 이유 한 줄 메모

☐ MOC 업데이트 (선택):
  - 관련 MOC가 있다면 새 노트 추가
  - 없다면 나중을 위해 메모만
```

**중요**: 완벽한 연결보다 작은 시도가 중요. 1개 연결 = 성공!

---

## 🎁 보너스: 월간 리뷰 (30분, 월 1회)

**매월 첫째 주 월요일 추가 15분 투자**

```
☐ 지난 달 생성한 영구메모 개수 확인
☐ 가장 많이 연결된 노트 TOP 3 확인
☐ 새 MOC 생성 필요성 평가:
  - 5개 이상의 관련 노트가 있는 주제가 있는가?
  - 설교 시리즈를 준비 중인 주제가 있는가?
☐ 지식 공백 리스트 작성:
  - 더 공부하고 싶은 주제 3개
  - 다음 달 독서 계획과 연결
```

## 💡 실패하지 않는 비결

### 1. **타이머 사용 필수**
- 15분 초과하지 말 것
- 미완료여도 멈추기
- 다음 주에 이어서 하기

### 2. **완벽주의 버리기**
- 승격 조건 애매하면 → 유지
- 연결 안 보이면 → 다음 주 시도
- Inbox 남아있어도 → 괜찮음

### 3. **누적 효과 믿기**
```
1주: 작은 변화 (체감 안 됨)
4주: 시스템 익숙해짐
12주: 명확한 패턴 발견
52주: 지식 네트워크 혁명
```
