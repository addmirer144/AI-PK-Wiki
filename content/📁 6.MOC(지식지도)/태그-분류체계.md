## 📋 개요

이 문서는 Obsidian 볼트의 모든 노트에서 일관된 태그 시스템을 사용하기 위한 표준 가이드입니다. 2025년 11월 태그 표준화 프로젝트를 통해 수립되었습니다.

**핵심 원칙**:
- ✅ YAML 프론트매터 형식 사용
- ✅ 계층적 태그보다 단순 태그 선호
- ✅ 카테고리 태그 + 주제 태그 조합
- ❌ 인라인 해시태그(#태그) 사용 금지

## 🏷️ 표준 태그 형식

### YAML 프론트매터 형식 (권장)

```yaml
---
tags:
  - 영구메모
  - 신학
  - 기도
  - 리더십
date: YYYY-MM-DD
type: permanent_note
---
```

### 파일 타입별 필수 메타데이터

#### 영구메모 (Permanent Notes)
```yaml
---
tags:
  - 영구메모
  - [주제1]
  - [주제2]
date: YYYY-MM-DD
type: permanent_note
---
```

#### MOC (Maps of Content)
```yaml
---
tags:
  - MOC
  - [주제1]
  - [주제2]
date: YYYY-MM-DD
type: moc
---
```

#### 문헌메모 (Literature Notes)
```yaml
---
tags:
  - 문헌메모
  - [주제1]
  - [주제2]
date: YYYY-MM-DD
author: [저자명]
source: "[출처]"
type: literature_note
---
```

#### 설교
```yaml
---
tags:
  - 설교
  - [청중]
  - [성경책]
  - [주제]
date: YYYY-MM-DD
audience: [성인/청소년/유아유치/전체]
duration: [시간]
series: [시리즈명 또는 단독]
type: sermon
---
```

## 🔧 태그 사용 가이드라인

### ✅ 좋은 태그 사용 예

```yaml
---
tags:
  - 영구메모
  - 리더십
  - 경제정의
  - 느헤미야
  - 개혁
date: 2025-10-13
type: permanent_note
---
```

**이유**:
- 카테고리 태그 명확 (`영구메모`)
- 주제 태그 구체적 (`리더십`, `경제정의`)
- 성경 인물 포함 (`느헤미야`)
- 5개 이하로 간결

### ❌ 피해야 할 태그 사용 예

```markdown
**태그**: #영구메모 #리더십-교회 #느헤미야서연구 #2025년
```

**문제점**:
- ❌ YAML 형식 아님
- ❌ 계층적 태그 사용 (`리더십-교회`)
- ❌ 너무 구체적 (`느헤미야서연구`)
- ❌ 시간 정보를 태그로 사용 (`2025년` → `date` 필드 사용)

## 📖 주요 태그 정의

### 영구메모 (Permanent Note)
**정의**: 나만의 언어로 다시 쓴, 재사용 가능한 핵심 통찰
**특징**:
- 원자적 (하나의 아이디어)
- 재사용 가능
- 다른 노트와 연결 풍부
**예시**: [[고레스-현상과-하나님의-구원사적-주권]]

### MOC (Map of Content)
**정의**: 특정 주제의 모든 관련 노트를 연결하는 지식 지도
**특징**:
- 인덱스 역할
- 주제별 큐레이션
- 학습 경로 제시
**예시**: [[느헤미야_MOC]], [[🗺️ 종교개혁-MOC]]

### 문헌메모 (Literature Note)
**정의**: 특정 자료(책/논문/영상)의 내용을 정리한 노트
**특징**:
- 저자 의견 정리
- 출처 명확
- 나중에 영구메모로 발전
**예시**: [[카푸친_원숭이_불평등_실험_Frans_de_Waal]]

## 🎯 태그 선택 프로세스

1. **카테고리 태그 선택** (필수, 1개만)
   - 이 노트의 유형은? → `영구메모`, `MOC`, `문헌메모`, `설교` 등

2. **주제 태그 추가** (2-5개 권장)
   - 이 노트의 주요 주제는? → 신학, 리더십, 기도 등
   - 관련된 성경 인물/책은? → 느헤미야, 다니엘 등
   - 어떤 분야와 연결되는가? → 목회, 현대사회 등

3. **메타데이터 추가**
   - `date`: 작성일
   - `type`: 파일 타입
   - (문헌메모) `author`, `source`
   - (설교) `audience`, `duration`, `series`

## 🔄 기존 노트 태그 업데이트 가이드

### 단계별 프로세스

1. **파일 읽기**
   - 기존 태그 형식 확인
   - 인라인 해시태그 찾기

2. **YAML 프론트매터 생성**
   ```yaml
   ---
   tags:
     - [카테고리 태그]
     - [주제 태그들]
   date: YYYY-MM-DD
   type: [파일 타입]
   ---
   ```

3. **인라인 해시태그 제거**
   - `**태그**: #태그1 #태그2` → 삭제
   - 본문 중 `#태그` → 제거 또는 위키링크로 변환

4. **검증**
   - 카테고리 태그 1개만 있는지 확인
   - 주제 태그 2-5개 적절한지 확인
   - date 필드 존재하는지 확인

## 🆘 FAQ

### Q1: 카테고리 태그를 여러 개 붙일 수 있나요?
**A**: 아니요. 하나의 노트는 정확히 하나의 카테고리 태그만 가져야 합니다.
- ✅ `영구메모`
- ❌ `영구메모`, `개념노트` (동시 사용 불가)

### Q2: 인라인 해시태그(#태그)는 왜 안 되나요?
**A**:
- YAML 프론트매터가 더 구조화되어 있고, 검색/필터링이 쉽습니다
- Dataview 플러그인과의 호환성이 좋습니다
- 일관성을 유지하기 쉽습니다

### Q3: 태그가 너무 많으면 어떡하나요?
**A**: 2-5개가 적정합니다. 너무 많으면:
- 검색 시 노이즈 증가
- 관리 부담 증가
- 핵심 주제 흐림

대신 wikilink `[[]]`로 다른 노트와 연결하세요.

### Q4: 날짜를 태그로 사용해도 되나요?
**A**: 아니요. 날짜는 `date` 필드에 별도로 기록합니다:
```yaml
date: 2025-11-05
```
❌ `tags: [2025년, 11월]` (X)

### Q5: 성경 본문은 어떻게 태그하나요?
**A**:
- 성경 **책** 이름: 태그로 추가 (`마태복음`, `창세기`)
- 성경 **장/절**: 제목이나 본문에 명시, 태그 불필요
  - 예: `마태복음 6:22-23` → 제목에 포함
  - 태그: `마태복음`, `산상수훈`
